# UI Release Evidence

These screenshots are generated by the deterministic Playwright portfolio harness. They use the
committed synthetic invoice PDF and route-level fixture data so every page can be reviewed without
credentials or provider drift. They prove rendered product behavior and responsive composition;
they are not production usage or model-accuracy evidence.

The release scope contains the eight pages below. Settings is intentionally absent because no
approved visual reference, persisted audited backend contract, or authorization model exists for
it; the product does not advertise a placeholder capability.

## Responsive Matrix

The capture command checks every primary page for document-level horizontal overflow before
writing the image.

| Viewport | Location |
| --- | --- |
| 1536 x 1024 | `docs/assets/screenshots/*.png` |
| 1280 x 800 | `docs/assets/screenshots/compact/*.png` |
| 1024 x 768 | `docs/assets/screenshots/tablet/*.png` |
| 390 x 844 | `docs/assets/screenshots/mobile/*.png` |

Regenerate the complete matrix with:

```powershell
Push-Location frontend
npm run capture:portfolio
Pop-Location
```

The fixture data is intentionally isolated under `frontend/e2e`; live application metrics and
business claims continue to come only from authenticated backend contracts.
