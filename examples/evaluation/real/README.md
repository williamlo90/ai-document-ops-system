# Real Labeled Evaluation Set

## Dataset

Current size: **1 public/synthetic invoice**.

| Document ID | Source | Expected Fields |
|---|---|---|
| `sample_invoice` | `sample_invoice.pdf` - included in the project root | 8 |

This is a tiny bootstrap dataset. It is sufficient to prove the evaluation pipeline works end-to-end but is not a production-grade benchmark.

## File Layout

| File | Description |
|---|---|
| `expected_real_invoices.json` | Hand-labeled ground truth for each PDF |
| `predicted_real_invoices.json` | Extraction output from the provider pipeline |
| `real_evaluation_report.json` | Output of `evaluate_invoices.py` comparing expected vs predicted |
| `README.md` | This file |

## How To Generate Predictions

```powershell
# Requires real API keys in .env (MISTRAL_API_KEY, EXTRACTOR_API_KEY, EXTRACTOR_ENDPOINT)
python scripts/run_real_fixture_extraction.py examples/evaluation/real/predicted_real_invoices.json
```

If no API keys are set, the script will refuse to run (safety guard). Use mock provider output as a placeholder only.

## How To Evaluate

```powershell
python scripts/evaluate_invoices.py examples/evaluation/real/expected_real_invoices.json examples/evaluation/real/predicted_real_invoices.json
```

## Known Limitations

- Single-document bootstrap. Accuracy results are not statistically meaningful.
- Predicted values were generated by the real provider pipeline (Mistral OCR + LLM JSON extractor). Mock provider predictions are used only when no API keys are configured.
- No multi-currency, multi-vendor, ambiguous-layout, or handwritten invoices.
